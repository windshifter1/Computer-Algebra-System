# Computer Algebra System

A redesigned and more user-friendly version of the original CAS created by the owner of [Maths From Nothing](https://mathsfromnothing.au/).

This project focuses on improving the visual design of the original CAS (no underlying functionality was changed).

## Original Project

The original CAS was developed independently by the owner of [Maths From Nothing](https://mathsfromnothing.au/) and is the original and most actively maintained version.
It is accessible [HERE](https://mathsfromnothing.au/wp-content/uploads/algebraprogramnew/index.html) 
or by navigating to the 'Maths From Nothing' website and clicking on the 'Computer Algebra System' page in the navigation menu.

Please refer to the original project for the latest updates and bugfixes.

## This Version

This version contains visual and user-experience improvements.
This may occasionally be behind the original in terms of updates and bugfixes.
It can be accessed [HERE](https://windshifter1.github.io/Computer-Algebra-System/Algebra.html)
